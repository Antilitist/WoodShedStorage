# Wood Shed Storage v0.2.0 (testing)

## Enable
Mods → **Wood Shed Storage** → Accept → restart if needed.

## Build
1. **Carpentry 4**
2. Build menu → **Furniture** → **Wood Shed**
3. Hammer + saw, 12 planks, 10 nails, 2 hinges, 4 logs

## Expect
- Console: `[WoodShedStorage] WoodShedStorageCode loaded.`
- On place: `[WoodShedStorage] OnCreate OK capacity=250`
- Open like a crate; store wood
